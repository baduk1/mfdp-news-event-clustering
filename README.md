# Помощник для сопоставления товарных предложений

Учебный проект My First Data Project: помощник специалиста по товарному каталогу интернет-магазина.

Сервис будет сравнивать предложения с учётом модели и комплектации, показывать существенные различия и помогать разбирать неоднозначные случаи. Для первой версии выбрана категория SSD. Основной исследовательский источник данных: [MaDI-Bench Products](https://github.com/wbsg-uni-mannheim/MaDI-Bench).
